# Phishing-Website-Detection
Technologies: Python, Machine Learning, Random Forest, Pandas, NumPy, Scikit-learn

Project Overview:
Developed a machine learning-based system to identify whether a website URL is legitimate or potentially phishing. The system extracts URL-based features such as URL length, number of dots, special characters, and the position of the '@' symbol. A Random Forest classifier was used to predict phishing websites, achieving approximately 96% accuracy.

Used a structured dataset containing website URLs and their corresponding phishing or legitimate labels. The data was organized into rows representing individual URLs and columns representing extracted features. Pandas and NumPy were used for data processing and manipulation.
